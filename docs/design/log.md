# 审计日志

> ⏳ **正文待补。** 本页是**审计日志**的设计口径：现在能用什么、目标口径是什么。
> 两段口径（**下一批**与**未来**）的权威声明在
> [2.0.x 路线图](../roadmap/2.0.x/roadmap.md) §3，本页只对齐，不另立口径。
>
> 在目标口径落地之前，本页只做占位，不把目标当成既有能力。

## 现在能用的（实现现状，仅供对照）

- 强制日志：`[Read]` / `[Write]` / `[Change]` / `[Error]` 四个级别，外加进程结构三行
  `[Start]` / `[Link]` / `[Send]`。去向可改（`log="stderr"` 默认 / `"stdout"` / 文件路径），
  **不可整体关闭**。
- 写全量（含 `op=skip`「想改没改」与 `op=noop`「本批声明已满足」），读按事务去重（`n=`）。
- 每条写记录带调用点（`at=app/config.py:12`）、pid 与可选 `identity=`。
- `audit=True` 时再追加一份 `<home>/audit.log`（`0600`、只追加、按大小轮转）；
  默认**不开**。

## 目标口径（尚未实现）

按批次分成两段（批次口径见 [2.0.x 路线图](../roadmap/2.0.x/roadmap.md)，那里是先后顺序的
唯一声明）：

### 下一批

- 两个互不影响的通道：**文件通道强制、永远全量**；**终端通道可选、可按级别筛选**
  （筛选语义是「刷终端时只刷哪些级别」，允许为空 = 终端全静）。
- `audit` 开关不存在：审计文件**恒写**，路径由独立参数给，默认 `<home>/audit.log`。

### 未来

- 落盘形式可插拔：明文（默认）/ 纯二进制 / 二进制加密 / 明文加密；
  密钥由调用方提供，引擎不生成、不推导、不保管。
  **前置未定**：在不引新依赖、且 sink 只收参数的前提下，算法与密钥的落点要先定下来。
- 轮转与分流参数化（现有阈值与「一个文件装全部等级」都是写死的）。

**不在这两段里**：库只产出数据 —— 不发网络、不收函数式 sink（现状已经如此）。

细节与取舍见路线图 §3 与 §5；本页在它们落地时补齐。
